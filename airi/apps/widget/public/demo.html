Widget demo

Чат-виджет в правом нижнем углу. Нажми на пузырь, чтобы открыть.

Виджет грузится с CDN https://widget.airi.chat/ и обращается только к задеплоенному API.

Standard HTML

<script async src="https://widget.airi.chat/loader.js" data-client-key="widget_4fa870264c9a7ace351d9df40a8a0653"></script>

Paste this before the </body> tag. API URL — production only.

Next.js / SSR

<Script
  src="https://widget.airi.chat/loader.js"
  data-client-key="widget_4fa870264c9a7ace351d9df40a8a0653"
  strategy="afterInteractive"
/>

Make sure to import Script from next/script.
